# renderport

Render structured JSON port payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/renderport/

## Install / run

```bash
git clone https://github.com/theworker02/renderport.git
cd renderport
node src/cli.js
node --test
```
